# BLUEPRINT BOT

Бот сервера-студии BLUEPRINT: приём заказов тикетами и девять оформленных панелей.
Движок тот же, что у клан-бота, но это **отдельное приложение Discord** — свой токен, свой сервер, свой `config.json`.

Весь текст панелей — украинский, правится в `config.json` без единой строчки кода.

---

## Что внутри

| Команда | Что делает |
|---|---|
| `/panel` | Панель заказа с кнопкой «Замовити оформлення» (баннер START YOUR PROJECT) |
| `/rules` | Правила сервера (баннер INFORMATION) |
| `/announce тип:` | Инфопанель: `welcome`, `services`, `portfolio`, `reviews`, `community`, `help`, `howto`, `boosts` |
| `/setup` | Категория заявок, архив, роль менеджеров, роль клиента, канал логов |
| `/apply` | Открыть форму заказа без панели |
| `/ticket close\|add\|remove\|info` | Управление открытой заявкой |
| `/sync-roles` | Выдать автороль всем, кто уже на сервере |

Форм две: **заказ оформления** (что нужно, ссылка на сервер, бюджет, срок, референсы) и **покупка бустов** (сколько бустов, сервер, срок, оплата). Панель бустов несёт свою кнопку, на главную панель форма бустов не выводится.
Заявка создаёт приватный канал `замовлення-0001`, который видят только клиент и менеджеры.

## Запуск

1. **Создать приложение**: [Developer Portal](https://discord.com/developers/applications) → New Application → `BLUEPRINT` → вкладка Bot → Reset Token.
2. `cp .env.example .env` и вписать `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`.
3. **Пригласить на сервер** (подставить свой CLIENT_ID):
   `https://discord.com/api/oauth2/authorize?client_id=CLIENT_ID&permissions=268561424&scope=bot%20applications.commands`
4. `npm install`
5. `npm run deploy` — зарегистрировать слэш-команды на сервере.
6. `npm start`
7. На сервере: `/setup категорія:🛒 ЗАМОВЛЕННЯ менеджери:@Manager` — иначе заявки упадут в корень сервера.

## Хостинг

```
npm run pack
```

Собирает `dist/blueprint-bot.tar.gz` (без `node_modules`, с `.env` внутри — никому не пересылать).
Залить на bot-hosting.net → Files → Upload → Extract (Same folder), стартовая команда:

```
npm install --omit=dev && npm start
```

Это **второй** бот: у клан-бота свой токен и свой слот на хостинге. Один слот — один процесс.

## Правка текстов

- тексты панелей — `config.json` → `panel`, `rules`, `announcements`
- вопросы формы — `config.json` → `forms[0].questions` (максимум 5 на одно окно, дальше бот сам разобьёт на шаги)
- баннеры — `assets/`, имя файла прописано в панели полем `bannerFile`
- цена оформления: в `announcements.services` сейчас «узнаёте в заявке» — впиши конкретные суммы в пакеты, когда определишься
- цена бустов: `announcements.boosts` → блок «СКІЛЬКИ ЦЕ КОШТУЄ», сейчас 1$ за буст
- у панели бустов нет баннера (`bannerFile: ""`) — добавь картинку в `assets/` и впиши имя файла

После правки `config.json` достаточно перезапустить бота. `npm run deploy` нужен только когда меняются сами команды.
